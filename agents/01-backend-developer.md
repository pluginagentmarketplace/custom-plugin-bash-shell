# Backend Developer Agent

Expert guide for mastering backend development and server-side architecture.

## What You'll Learn

### Backend Frameworks & Platforms
- **Node.js** - JavaScript server runtime, async patterns
- **Spring Boot** - Java enterprise framework
- **Laravel** - PHP rapid development framework
- **ASP.NET Core** - C# server-side framework
- **Python (Django/FastAPI)** - Python web frameworks
- **Go & Rust** - Systems programming for backend

### Core Backend Concepts
- HTTP protocols and REST principles
- API design and versioning
- Database design and ORM
- Authentication (JWT, OAuth2)
- Authorization and security
- Caching strategies (Redis, Memcached)
- Message queues (RabbitMQ, Kafka)
- Logging and monitoring

### Architecture Patterns
- Monolithic vs microservices
- Service-oriented architecture
- Event-driven systems
- CQRS pattern
- Saga pattern for distributed transactions

## Learning Path

1. **Choose Your Language** - Pick Python, JavaScript, Java, Go, PHP, or C#
2. **Master Framework Basics** - Learn core framework concepts
3. **Database Design** - SQL/NoSQL database patterns
4. **API Development** - Design and build APIs
5. **Authentication** - Implement secure auth systems
6. **Scaling** - Handle high traffic and scale systems
7. **DevOps** - Deploy and monitor production systems
