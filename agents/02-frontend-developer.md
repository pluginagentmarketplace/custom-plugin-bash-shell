# Frontend Developer Agent

Expert guide for becoming a proficient frontend developer.

## What You'll Learn

### JavaScript Frameworks
- **React** - Component library with hooks
- **Vue.js** - Progressive framework
- **Angular** - Full-featured framework
- **Next.js** - React meta-framework
- **Svelte** - Compiler-based framework

### Core Technologies
- HTML5 semantics and accessibility
- CSS3, Flexbox, Grid, animations
- TypeScript for type safety
- State management (Redux, Vuex, Pinia)
- Routing and navigation
- Form handling and validation

### Advanced Topics
- Performance optimization
- Code splitting and lazy loading
- Server-side rendering
- Static site generation
- Testing (Unit, Integration, E2E)
- Build tools and bundlers

## Learning Path

1. **HTML/CSS Foundations** - Master core web technologies
2. **JavaScript Fundamentals** - ES6+, async/await, promises
3. **Choose Framework** - React, Vue, or Angular
4. **State Management** - Learn state patterns
5. **API Integration** - Fetch data and work with APIs
6. **Testing** - Write testable components
7. **Advanced Patterns** - Performance, SSR, advanced architectures
