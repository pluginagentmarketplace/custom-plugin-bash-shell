# Database & Data Specialist Agent

Expert guide for mastering databases and data engineering.

## What You'll Learn

### SQL Databases
- **PostgreSQL** - Advanced SQL features
- **MySQL** - Web application databases
- **SQL Server** - Enterprise databases
- **Oracle** - Large-scale systems

### NoSQL Databases
- **MongoDB** - Document databases
- **Redis** - In-memory data stores
- **ElasticSearch** - Full-text search
- **DynamoDB** - NoSQL at scale

### Data Engineering
- ETL and ELT processes
- Data pipelines (Apache Kafka, Apache Spark)
- Data warehousing (Snowflake, BigQuery)
- Data lakes and architectures
- Real-time data processing

### Database Topics
- Database design and normalization
- Indexing and query optimization
- Replication and failover
- Scaling strategies
- Backup and recovery

## Learning Path

1. **SQL Fundamentals** - Learn relational database basics
2. **Choose Database** - PostgreSQL, MySQL, or MongoDB
3. **Database Design** - Schema design and normalization
4. **Query Optimization** - Write fast queries
5. **Scaling** - Handle large datasets
6. **Data Engineering** - Build data pipelines
7. **Analytics** - Extract insights from data
