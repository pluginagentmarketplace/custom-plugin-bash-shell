# 🗄️ Database & Data Specialist Agent

**Expert comprehensive guide for mastering databases, data engineering, ETL pipelines, and building data-driven systems.**

Your journey from junior database developer to senior data engineer/architect expertise in handling massive datasets and building scalable data platforms.

## 🎯 Career Path Overview

### Role Progression
1. **Junior Database Developer** (0-2 years) - SQL, basic database administration
2. **Mid-Level Data Engineer** (2-5 years) - ETL pipelines, data modeling, optimization
3. **Senior Data Engineer** (5-8+ years) - Architecture, pipeline design, optimization
4. **Data Architect/Principal** (8+ years) - Enterprise data strategy, innovation

### Salary Progression (2024)
- **Junior**: $85K - $125K
- **Mid-Level**: $125K - $165K
- **Senior**: $165K - $230K
- **Architect/Principal**: $210K - $380K+

## 🗃️ SQL Databases Deep Dive

### PostgreSQL ⭐⭐⭐⭐⭐
**Profile**: Advanced, feature-rich, reliable, ACID-compliant

**Why PostgreSQL**:
- Most advanced open-source database
- JSONB support (semi-structured data)
- Full-text search capabilities
- Extensible (custom types, functions)
- Window functions and CTEs
- Array and range types
- Best for: Complex queries, data integrity, analytics

**Advanced Features**:
- JSONB and JSON operators
- Full-text search and trigram similarity
- Window functions (ROW_NUMBER, RANK, LAG, LEAD)
- Common Table Expressions (CTEs)
- Recursive queries
- Array and range types
- Collation and localization
- Custom types and domains

### MySQL ⭐⭐⭐⭐
**Profile**: Wide adoption, reliable, good performance

**Why MySQL**:
- Wide hosting support
- Good for web applications
- InnoDB storage engine (ACID)
- Replication built-in
- Best for: Web apps, scaling, reliability

## 📊 Data Engineering Concepts

### ETL vs ELT
- **ETL** (Extract, Transform, Load) - Process before loading
- **ELT** (Extract, Load, Transform) - Process after loading in warehouse

### Data Pipeline Architecture
1. **Extraction** - Collect data from sources
2. **Transformation** - Clean, enrich, validate
3. **Loading** - Store in warehouse/lake
4. **Analytics** - Query and analyze
5. **Visualization** - Create dashboards and reports

### Popular Tools
- **Airflow** - Workflow orchestration
- **Spark** - Big data processing
- **Kafka** - Stream processing
- **dbt** - Data transformation
- **Snowflake** - Cloud data warehouse
- **BigQuery** - Google's data warehouse
- **Redshift** - AWS data warehouse
