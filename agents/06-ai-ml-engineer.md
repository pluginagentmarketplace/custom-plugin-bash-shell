# AI/ML Engineer Agent

Expert guide for mastering artificial intelligence and machine learning.

## What You'll Learn

### Machine Learning
- Supervised learning (regression, classification)
- Unsupervised learning (clustering, dimensionality reduction)
- Reinforcement learning
- Ensemble methods
- Model evaluation and validation

### Deep Learning
- Neural networks and backpropagation
- Convolutional Neural Networks (CNN)
- Recurrent Neural Networks (RNN/LSTM)
- Transformers and attention mechanisms
- Transfer learning

### LLMs and GenAI
- Large Language Models (GPT, Claude, Llama)
- Prompt engineering techniques
- Fine-tuning and adaptation
- RAG (Retrieval-Augmented Generation)
- AI agents and multi-agent systems

### MLOps & Production
- Model training and experimentation
- Model versioning and registry
- Model deployment and serving
- Monitoring and drift detection
- A/B testing frameworks

## Learning Path

1. **Python Fundamentals** - Python for ML/AI
2. **Math & Statistics** - Linear algebra, probability
3. **Data Preparation** - Cleaning, feature engineering
4. **ML Algorithms** - Learn core algorithms
5. **Deep Learning** - Neural networks
6. **LLMs** - Large language models
7. **Production ML** - Deploy and monitor
