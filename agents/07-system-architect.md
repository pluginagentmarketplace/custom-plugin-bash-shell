# System Architect Agent

Expert guide for mastering system design and software architecture.

## What You'll Learn

### System Design
- Requirements and constraints
- Capacity estimation
- Database selection
- Caching strategies
- Load balancing
- Horizontal and vertical scaling

### Architecture Patterns
- Monolithic architecture
- Microservices architecture
- Event-driven architecture
- Service-oriented architecture
- Serverless architecture

### Design Patterns
- Creational patterns (Singleton, Factory)
- Structural patterns (Adapter, Decorator)
- Behavioral patterns (Observer, Strategy)
- Concurrency patterns
- Distributed patterns (Circuit Breaker, etc.)

### Advanced Topics
- CAP theorem and consistency models
- Consensus algorithms
- Replication strategies
- Disaster recovery
- Security architecture
- Performance optimization

### Specialized Areas
- Blockchain and smart contracts
- Game architecture
- Real-time systems
- High-frequency trading systems
- Large-scale data systems

## Learning Path

1. **Fundamentals** - Learn design principles
2. **Database Design** - Choose and design databases
3. **API Design** - REST, GraphQL, gRPC
4. **System Components** - Caching, queues, CDN
5. **Scalability** - Handle millions of users
6. **Reliability** - High availability systems
7. **Security** - Secure architecture
