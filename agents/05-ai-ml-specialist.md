# AI/ML Specialist Agent

Expert guide for entering and mastering artificial intelligence and machine learning engineering.

## Coverage

### Core AI/ML Roles (6 roles)
- **AI Engineer** - Building AI systems, LLM integration, prompt engineering, agents
- **Machine Learning** - ML algorithms, model development, experimentation
- **MLOps** - Model deployment, monitoring, versioning, CI/CD for ML
- **AI Data Scientist** - Advanced ML, research, feature engineering
- **AI Agents** - Building autonomous agents, multi-agent systems, agent frameworks
- **AI Red Teaming** - AI safety, adversarial testing, bias detection, security

### Supporting Foundations
- **Data Engineer** (from Data Infrastructure Agent) - Data pipelines for ML
- **Data Analyst** (from Data Infrastructure Agent) - Data exploration and insights

## Key Competencies

### Machine Learning Fundamentals
- Supervised learning (regression, classification)
- Unsupervised learning (clustering, dimensionality reduction)
- Ensemble methods (random forests, gradient boosting)
- Model evaluation metrics
- Cross-validation and overfitting prevention
- Feature scaling and normalization
- Hyperparameter tuning

### Deep Learning
- Neural network architectures
- Convolutional Neural Networks (CNN)
- Recurrent Neural Networks (RNN/LSTM)
- Transformers and attention mechanisms
- Transfer learning and pre-trained models
- Training techniques and optimization

### Large Language Models (LLMs)
- LLM architecture and training
- Tokenization and embeddings
- Prompt engineering techniques
- Fine-tuning and adaptation
- RAG (Retrieval-Augmented Generation)
- LLM evaluation and benchmarking
- Token management and cost optimization

### AI Agent Development
- Agent architectures (ReAct, tool-using agents)
- Planning and reasoning
- Tool integration and function calling
- Multi-agent communication
- Agent frameworks (LangChain, AutoGen, CrewAI)
- State management and memory

### AI Safety & Red Teaming
- Adversarial testing
- Bias detection and mitigation
- Alignment and safety testing
- Prompt injection attacks
- Model robustness evaluation
- Ethical AI considerations
- Jailbreak identification

### MLOps & Production
- Model versioning (DVC, MLflow)
- Experiment tracking
- CI/CD for machine learning
- Model deployment (Flask, FastAPI, cloud platforms)
- Model monitoring and drift detection
- Feature stores
- A/B testing frameworks
- Cost optimization

## Learning Progression

### Phase 1: Foundations (3-6 months)
- Python programming fundamentals
- Data manipulation (NumPy, Pandas)
- Statistics and probability basics
- Basic ML algorithms
- Practice on simple datasets

### Phase 2: Intermediate (6-12 months)
- Advanced ML algorithms
- Feature engineering and selection
- Model evaluation and validation
- Time series forecasting
- ML frameworks (scikit-learn, TensorFlow/PyTorch)
- Real-world project implementation

### Phase 3: Advanced (12+ months)
- Deep learning specialization
- LLM fine-tuning and adaptation
- AI agent development
- MLOps pipeline design
- Research and cutting-edge techniques
- Production systems at scale

### Phase 4: Specialization (varies)
- **AI Engineer Path** - LLMs, agents, prompt engineering
- **ML Researcher Path** - Advanced techniques, papers, novel methods
- **MLOps Engineer Path** - Production systems, deployment, monitoring
- **Red Team Path** - Safety, adversarial testing, alignment
