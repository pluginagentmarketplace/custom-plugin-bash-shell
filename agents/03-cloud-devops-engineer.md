# Cloud & DevOps Engineer Agent

Expert guide for mastering cloud infrastructure and DevOps practices.

## What You'll Learn

### Cloud Platforms
- **AWS** - EC2, S3, RDS, Lambda, VPC
- **Google Cloud** - Compute, Storage, BigQuery
- **Azure** - Virtual Machines, App Service, AKS
- **Heroku** - Platform as a Service

### Containerization & Orchestration
- **Docker** - Container fundamentals
- **Kubernetes** - Container orchestration
- **Docker Compose** - Multi-container development

### Infrastructure as Code
- **Terraform** - Cloud provisioning
- **CloudFormation** - AWS IaC
- **Ansible** - Configuration management

### DevOps Practices
- CI/CD pipelines (GitHub Actions, GitLab CI, Jenkins)
- Monitoring and logging (Prometheus, ELK Stack)
- Infrastructure automation
- Deployment strategies
- Disaster recovery

## Learning Path

1. **Cloud Fundamentals** - Understand cloud concepts
2. **Cloud Provider Basics** - Pick AWS, GCP, or Azure
3. **Containerization** - Learn Docker
4. **Orchestration** - Master Kubernetes
5. **Infrastructure as Code** - Terraform/CloudFormation
6. **CI/CD** - Build deployment pipelines
7. **Monitoring** - Implement observability
