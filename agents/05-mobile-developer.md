# Mobile Developer Agent

Expert guide for mastering mobile app development.

## What You'll Learn

### Native Mobile Development
- **Android** - Kotlin, Jetpack, Material Design
- **iOS** - Swift, SwiftUI, Cocoa frameworks
- **Windows Mobile** - C# and UWP

### Cross-Platform Development
- **Flutter** - Dart-based framework
- **React Native** - JavaScript framework
- **Xamarin** - C# cross-platform

### Core Mobile Concepts
- App architecture patterns
- UI/UX design for mobile
- Battery and performance optimization
- Local storage and databases
- Networking and APIs
- App lifecycle management
- Testing and debugging

### Mobile Security
- Secure storage
- API authentication
- Data encryption
- Permission handling
- Secure communication

## Learning Path

1. **Choose Platform** - Native or cross-platform
2. **Language Fundamentals** - Kotlin/Swift/Dart/JavaScript
3. **UI Development** - Learn framework UI systems
4. **State Management** - Handle app state
5. **API Integration** - Connect to backends
6. **Local Storage** - Persist data
7. **Testing & Deployment** - Prepare for app stores
