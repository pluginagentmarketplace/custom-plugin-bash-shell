# AI/ML Frameworks

## Core Libraries

### scikit-learn (Classic ML)
- Algorithms: decision trees, SVMs, clustering
- Best for: Traditional ML, classification
- Learning curve: Easy
- Performance: Single machine

### TensorFlow (Deep Learning)
- Creator: Google
- Best for: Production, large scale
- Learning curve: Hard
- Performance: Excellent (GPU/TPU optimized)

### PyTorch (Research ML)
- Creator: Facebook
- Best for: Research, flexibility
- Learning curve: Medium
- Performance: Great (GPU optimized)

## ML Workflow

```
Data Collection
    ↓
Data Preprocessing
    ↓
Feature Engineering
    ↓
Model Selection
    ↓
Training
    ↓
Evaluation
    ↓
Hyperparameter Tuning
    ↓
Production Deployment
```

## Common Tasks
