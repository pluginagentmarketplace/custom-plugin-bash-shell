# Data Engineering

## Data Pipeline Stages

1. **Extraction** - Collect data from sources
2. **Transformation** - Clean, enrich, process data
3. **Loading** - Store in warehouse/lake
4. **Analytics** - Query and analyze
5. **Visualization** - Create dashboards

## Key Technologies

### ETL Tools
- Apache Airflow (orchestration)
- Talend (ETL platform)
- Informatica (enterprise)
- dbt (transformation)

### Processing
- Apache Spark (big data)
- Apache Kafka (streaming)
- Apache Flink (real-time)

### Warehousing
- Snowflake
- BigQuery
- Redshift
- Azure Synapse

### Storage
- Data Lakes (S3, HDFS, Azure Data Lake)
- Data Warehouses
- Data Marts

## Concepts

- OLTP vs OLAP
- Dimensional modeling
- Star schema, snowflake schema
- Data quality
- Data governance
- Real-time vs batch processing
