# DevOps Tools & Practices

## Containerization

### Docker
- Images: reproducible environments
- Containers: isolated applications
- Registry: image storage
- Docker Compose: multi-container apps

## Orchestration

### Kubernetes
- Pods: smallest deployable unit
- Services: networking and LB
- Deployments: application updates
- StatefulSets: stateful apps
- Jobs: batch processing

## Infrastructure as Code

### Terraform
- HCL syntax
- Providers (AWS, GCP, Azure)
- Modules and reusability
- State management
- CI/CD integration

## CI/CD Pipelines

### GitHub Actions
- Workflows and jobs
- Triggers (push, PR, schedule)
- Actions (reusable tasks)
- Secrets management

### GitLab CI
- .gitlab-ci.yml
- Stages and jobs
- Runners
- Docker integration

## Monitoring & Logging

- Prometheus (metrics)
- Grafana (visualization)
- ELK Stack (logging)
- Datadog (APM)

## Core Concepts

- Infrastructure as Code
- Continuous Integration
- Continuous Deployment
- Blue-green deployments
- Canary releases
- Infrastructure monitoring
