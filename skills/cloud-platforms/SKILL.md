# Cloud Platforms

## Quick Start - Pick Your Cloud

### AWS (Amazon)
- Market leader (33%)
- Best for: Everything, flexible
- Learning curve: Medium
- Certifications: AWS Certified Solutions Architect

### Google Cloud (GCP)
- Data and ML strength (11%)
- Best for: Data, AI/ML, BigQuery
- Learning curve: Medium
- Certifications: GCP Associate Cloud Engineer

### Azure (Microsoft)
- Enterprise strength (23%)
- Best for: .NET, enterprise
- Learning curve: Medium
- Certifications: Azure Administrator

## Core Services

### Compute
- EC2/Compute Engine/VMs
- Serverless (Lambda/Functions/Cloud Functions)
- Containers (ECS/GKE/AKS)

### Storage
- Object storage (S3/GCS/Blob)
- Block storage (EBS/Persistent Disk)
- Databases (RDS/Cloud SQL/Azure Database)

### Networking
- VPC and subnets
- Load balancing
- CDN (CloudFront/Cloud CDN)
- DNS (Route 53/Cloud DNS)

## Key Concepts

- Regions and availability zones
- Multi-region architecture
- Auto-scaling
- Cost optimization
- Security best practices
- Monitoring and logging
