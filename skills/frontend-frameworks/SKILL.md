# Frontend Frameworks

## Quick Start - Choose Framework

### React (Facebook)
- Component library
- Best for: Large apps, startups, jobs
- Learning curve: Medium
- Job market: Excellent (100K+ jobs)

### Vue.js (Community)
- Progressive framework
- Best for: Small to medium apps
- Learning curve: Easy
- Job market: Growing (20K+ jobs)

### Angular (Google)
- Full framework
- Best for: Enterprise apps
- Learning curve: Hard
- Job market: Stable (25K+ jobs)

## Core Skills

- JSX/Templates and components
- Hooks and state management
- Routing and navigation
- Form handling
- API integration
- Testing (Jest, React Testing Library)
- Performance optimization
- Accessibility (a11y)

## Modern Patterns

- Functional components
- Hooks and custom hooks
- Context API
- Render props
- Compound components
- Lazy loading
- Code splitting
