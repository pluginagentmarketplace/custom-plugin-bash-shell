# Career Progression

Plan your career growth. Understand progression paths, skill development, and advancement opportunities.

## Usage

```
/career-progression --from [current-role] --to [target-role]
```

## Examples

```
/career-progression --from junior-developer --to senior-architect
/career-progression --from frontend-developer --to fullstack-lead
/career-progression --from data-analyst --to machine-learning-engineer
```

## Progression Insights

- **Current Role Assessment** - Where you are now
- **Target Role Requirements** - What you need
- **Skills Gap** - Specific gaps to fill
- **Timeline** - Realistic progression timeframe
- **Intermediate Steps** - Stepping stones to target
- **Salary Growth** - Compensation progression
- **Leadership Skills** - Soft skills development
