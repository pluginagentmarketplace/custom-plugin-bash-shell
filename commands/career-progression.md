# Shell Scripting Career Progression

Plan your career growth in shell scripting and DevOps. Understand progression paths, skill development, and advancement opportunities.

## Usage

```
/career-progression --from [current-level] --to [target-role]
```

## Levels

| Level | Experience | Bash Skills |
|-------|------------|-------------|
| `junior` | 0-2 years | Basic scripts |
| `mid` | 2-5 years | Complex automation |
| `senior` | 5-8 years | Production systems |
| `lead` | 8+ years | Architecture, mentoring |
| `principal` | 10+ years | Strategy, standards |

## Target Roles

| Role | Description |
|------|-------------|
| `sysadmin` | System Administrator |
| `devops` | DevOps Engineer |
| `sre` | Site Reliability Engineer |
| `platform-lead` | Platform Engineering Lead |
| `architect` | Infrastructure Architect |

## Examples

```bash
/career-progression --from junior --to devops
/career-progression --from mid --to sre
/career-progression --from senior --to platform-lead
/career-progression --from devops --to architect
```

## Skills by Level

### Junior (0-2 years)
- Basic Bash scripting
- Linux fundamentals
- Git version control
- Simple automation

### Mid-Level (2-5 years)
- Complex shell scripts
- CI/CD pipelines
- Container basics
- Monitoring setup

### Senior (5-8 years)
- Production-grade scripts
- Infrastructure as Code
- Performance optimization
- Security hardening

### Lead/Principal (8+ years)
- Architecture decisions
- Team mentoring
- Standards & best practices
- Cross-team collaboration
