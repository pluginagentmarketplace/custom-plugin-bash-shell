# My Bash Learning Path

Get a personalized Bash learning path tailored to your goals, experience level, and available time.

## Usage

```
/my-learning-path [topic] --level [beginner|intermediate|advanced] --hours [weekly-hours]
```

## Topics

| Topic | Description | Est. Time |
|-------|-------------|-----------|
| `fundamentals` | Core Bash scripting | 4-6 hours |
| `text-processing` | grep, sed, awk | 6-8 hours |
| `file-operations` | File management | 4-6 hours |
| `process-management` | Jobs, signals, cron | 6-8 hours |
| `networking` | curl, ssh, ports | 6-8 hours |
| `automation` | CI/CD, testing | 8-12 hours |
| `complete` | Full Bash mastery | 40-60 hours |

## Examples

```bash
/my-learning-path fundamentals --level beginner --hours 5
/my-learning-path text-processing --level intermediate
/my-learning-path automation --level advanced --hours 10
/my-learning-path complete --level beginner --hours 8
```

## What You'll Get

- **Personalized Curriculum** - Exactly what YOU need to learn

## Learning Path Structure

```
Week 1-2: Foundation
├── Shell basics and navigation
├── Variables and data types
├── Control structures (if, for, while)
└── Functions and script organization

Week 3-4: Text Processing
├── grep patterns and regex
├── sed stream editing
├── awk data processing
└── Pipeline composition

Week 5-6: System Operations
├── File operations and permissions
├── Process management
├── Job scheduling with cron
└── Signal handling

Week 7-8: Advanced Topics
├── Network operations
├── CI/CD automation
├── Testing with Bats
└── Production best practices
```
