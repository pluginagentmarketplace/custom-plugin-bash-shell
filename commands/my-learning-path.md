# My Learning Path

Get a personalized learning path tailored to your goals, experience level, and timeframe.

## Usage

```
/my-learning-path [role] --duration [weeks] --level [beginner|intermediate|advanced]
```

## Examples

```
/my-learning-path react --duration 12 --level beginner
/my-learning-path backend --duration 6 --level intermediate
/my-learning-path ai-engineer --level advanced
```

## What You'll Get

- **Personalized Curriculum** - Exactly what YOU need to learn
- **Phase-by-Phase Breakdown** - Clear learning stages
- **Time Estimates** - How long each phase takes
- **Projects & Exercises** - Hands-on practice
- **Milestones** - Track your progress
- **Resources** - Curated learning materials
- **Career Tips** - Industry insights

## Features

✓ Adapts to your current level
✓ Customizable timeframe
✓ Real-world projects
✓ Progress checkpoints
✓ Community resources
✓ Interview preparation
✓ Job market insights
