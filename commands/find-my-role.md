# Find My Role

Discover your ideal developer role based on your interests, strengths, and career goals.

## Usage

```
/find-my-role --interests [keywords] --strengths [skills] --goals [career-goals]
```

## Examples

```
/find-my-role --interests web automation --strengths javascript python
/find-my-role --interests data ml --goals research innovation
/find-my-role --interests cloud infrastructure --strengths bash kubernetes
```

## How It Works

1. **Interest Matching** - Find roles aligned with your passions
2. **Skill Assessment** - See which roles fit your strengths
3. **Goal Alignment** - Consider your career objectives
4. **Job Market** - Factor in current demand
5. **Learning Path** - Estimate time to proficiency
6. **Recommendations** - Get ranked role suggestions
