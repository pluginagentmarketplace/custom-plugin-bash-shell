# Explore Roadmap

Explore and learn from a specific developer roadmap. Browse through the learning path for any of the 69+ developer roles.

## Usage

```
/explore-roadmap [role-name]
```

## Examples

```
/explore-roadmap python
/explore-roadmap react
/explore-roadmap kubernetes
/explore-roadmap ai-engineer
/explore-roadmap product-manager
```

## What You'll Learn

For each roadmap, you'll discover:
- **Learning Path** - Step-by-step progression
- **Core Concepts** - Essential topics to master
- **Tools & Technologies** - Popular frameworks and libraries
- **Best Practices** - Industry standards and patterns
- **Career Guidance** - How this role connects to others
- **Resources** - Where to learn more

## Example Output

When you run `/explore-roadmap react`, you'll get:
- React fundamentals (JSX, components, hooks)
- State management options
- Routing and forms
- Testing strategies
- Performance optimization
- Server-side rendering with Next.js
- Links to the official React roadmap
- Career progression options

## Integration with Agents

This command leverages the **Web Development Agent** for frontend frameworks and **Programming Fundamentals Agent** for language selection.

## Tips

- Run this command multiple times for different roles to compare paths
- Use `/compare-roles` to see differences between two roles
- Use `/learning-path` to get a personalized curriculum
- Use `/skill-assessment` to gauge your current level
