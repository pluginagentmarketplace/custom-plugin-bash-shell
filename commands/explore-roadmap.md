# Explore Roadmap

Deep dive into any of the 65+ developer roles from roadmap.sh. Get comprehensive learning paths, technologies, best practices, and career insights.

## Usage

```
/explore-roadmap [role-name]
```

## Examples

```
/explore-roadmap react
/explore-roadmap python
/explore-roadmap kubernetes
/explore-roadmap ai-engineer
/explore-roadmap system-design
```

## What You'll Get

- **Role Overview** - What the role does and why it matters
- **Required Skills** - Technical and soft skills needed
- **Technology Stack** - Tools, frameworks, languages
- **Learning Roadmap** - Step-by-step progression
- **Industry Standards** - Current best practices
- **Career Prospects** - Job market, salary ranges
- **Resources** - Courses, books, communities

## 65+ Supported Roles

**Backend**: Node.js, Spring Boot, Laravel, ASP.NET, PHP, Backend Generalist
**Frontend**: React, Vue, Angular, Next.js, CSS, HTML, Frontend Generalist
**Cloud**: AWS, GCP, Azure, Docker, Kubernetes, DevOps, Terraform
**Data**: PostgreSQL, MongoDB, Redis, Data Engineer, Data Analyst, ML
**Mobile**: Android, iOS, Flutter, React Native
**AI/ML**: Machine Learning, AI Engineer, Data Science, MLOps
**Architecture**: System Design, Software Architect, Design Patterns
**And 40+ more specialized roles!**
