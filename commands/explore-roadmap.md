# Explore Bash Roadmap

Deep dive into the Bash shell scripting learning path. Get comprehensive learning paths, technologies, best practices, and career insights.

## Usage

```
/explore-roadmap [topic]
```

## Available Roadmaps

| Roadmap | Description |
|---------|-------------|
| `fundamentals` | Bash syntax, variables, control flow |
| `text-processing` | grep, sed, awk mastery |
| `file-operations` | File management, permissions |
| `process-management` | Jobs, signals, daemons |
| `networking` | curl, ssh, network tools |
| `automation` | CI/CD, scripting, testing |
| `devops` | Shell for DevOps/SRE |
| `complete` | Full Bash mastery path |

## Examples

```bash
/explore-roadmap fundamentals
/explore-roadmap text-processing
/explore-roadmap automation
/explore-roadmap devops
/explore-roadmap complete
```

## What You'll Get

- **Topic Overview** - What the topic covers and why it matters
- **Required Skills** - Prerequisites and dependencies
- **Technology Stack** - Tools, commands, utilities
- **Learning Roadmap** - Step-by-step progression
- **Best Practices** - Production-grade patterns
- **Career Relevance** - How this skill helps your career
- **Resources** - Courses, books, communities
