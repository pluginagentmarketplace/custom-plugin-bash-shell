# Find Role

Discover developer roles that match your interests, skills, and career goals.

## Usage

```
/find-role [--interests keywords] [--skills current-skills] [--goals career-goals]
```

## Examples

```
/find-role --interests web automation
/find-role --skills python javascript --goals machine-learning
/find-role --interests cloud infrastructure --skills go
/find-role --goals startup equity remote-work
/find-role --interests design performance accessibility
```

## Self-Assessment for Role Fit

Ask yourself:
1. Do the day-to-day tasks interest me?
2. Do I want to specialize or generalize?
3. Do I prefer hands-on coding or architecture?
4. Is the job market demand important?
5. What's my preferred learning style?
6. How much career growth is available?

## Filters

You can combine filters:

```
/find-role --interests "web development" --skills python --goals "startup"
→ Result: Full-Stack, Backend, Frontend roles

/find-role --interests "machine learning" --goals "research"
→ Result: ML Engineer, AI Data Scientist, ML Research

/find-role --interests "management" --skills "backend"
→ Result: Engineering Manager path from backend
```

## Career Switching

If you're switching careers:
- Start with fundamental languages (Python, JavaScript)
- Build projects alongside learning
- Network with professionals in target role
- Consider bootcamps or structured programs
- Expect 3-12 months for specialization
