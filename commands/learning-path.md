# Learning Path

Get a personalized learning path for your target developer role, with estimated timeline and milestones.

## Usage

```
/learning-path [role] [--duration weeks] [--experience level]
```

## Examples

```
/learning-path python
/learning-path react --duration 12
/learning-path kubernetes --experience advanced
/learning-path full-stack --duration 6 --experience beginner
/learning-path ai-engineer --experience intermediate
```

## Duration Options

- `beginner` - 0-6 weeks
- `intermediate` - 6-12 weeks
- `advanced` - 12+ weeks

## Experience Levels

### Absolute Beginner
- No programming experience
- 12-20 weeks to competency
- Focus on fundamentals first
- Choose Python or JavaScript

### Beginner (Some programming)
- Know one language
- 8-16 weeks to competency
- Can skip language basics
- Ready for frameworks

### Intermediate
- 2+ years experience
- 4-12 weeks to specialize
- Jump to advanced topics
- Focus on architecture

### Advanced
- 5+ years experience
- 2-8 weeks to master
- Deep dive into specialization
- Build production systems

## Example Learning Path

### Python (Beginner, 12 weeks)

**Week 1-2: Python Fundamentals**
- Variables, data types, operators
- Control flow (if, loops)
- Functions and scope
- Resource: Official Python tutorial

**Week 3-4: Object-Oriented Programming**
- Classes and objects
- Inheritance and polymorphism
- Encapsulation
- Project: Build a simple game

**Week 5-6: Web Development Basics**
- Choose a framework (Flask or Django)
- HTTP and REST basics
- Templates and databases
- Project: Build a simple web app

**Week 7-12: Advanced Topics**
- APIs and databases
- Testing and debugging
- Deployment
- Choose specialization (web, data science, or automation)

## Customization

The path adapts based on:
- **Your background** - Experienced developers skip basics
- **Your goals** - Different specializations branch out
- **Time available** - Can accelerate or extend
- **Preferred learning style** - Hands-on projects vs theory

## Tips

- Adjust the duration based on your pace
- Don't skip fundamentals—they matter!
- Build projects alongside learning
- Join communities for peer support
