# Compare Roles

Compare two or more roles side-by-side. See differences in skills, learning time, job market, and career prospects.

## Usage

```
/compare-roles [role1] [role2] [role3] --aspect [all|skills|time|market]
```

## Examples

```
/compare-roles frontend backend
/compare-roles react vue angular
/compare-roles python javascript go
/compare-roles ai-engineer data-engineer ml-engineer
```

## Comparison Aspects

- **Skills Required** - What you need to learn
- **Learning Time** - How long to reach proficiency
- **Job Market** - Demand, salary, growth
- **Difficulty Level** - Learning curve
- **Specialization** - How focused vs generalist
- **Career Path** - Progression opportunities
- **Tools & Technologies** - Ecosystem
