# Project Ideas

Get hands-on project ideas to build real skills. Projects tailored to your current level and goals.

## Usage

```
/project-ideas [role] --level [beginner|intermediate|advanced] --type [web|api|mobile|ml|devops]
```

## Examples

```
/project-ideas react --level beginner
/project-ideas backend --level intermediate --type api
/project-ideas data-engineer --level advanced
/project-ideas ai-engineer --type ml
```

## Project Categories

- **Beginner** - Foundation building (1-2 weeks)
- **Intermediate** - Real-world features (2-4 weeks)
- **Advanced** - Production systems (4-8+ weeks)
