# Skill Assessment

Assess your current skills against a specific developer roadmap to identify gaps and next steps.

## Usage

```
/skill-assessment [role] [--format detailed|summary]
```

## Examples

```
/skill-assessment python
/skill-assessment react --format detailed
/skill-assessment kubernetes
/skill-assessment ai-engineer --format summary
```

## Assessment Format

### Summary (Default)
- Overall proficiency: Beginner/Intermediate/Advanced
- Estimated gap: X weeks to competency
- Top 3 areas to focus on
- Next recommended steps

### Detailed
- Score for each skill area (0-100%)
- Specific resources for weak areas
- Hands-on projects to practice
- Timeline to proficiency
- Comparison with industry standards

## Self-Assessment Questions

Answer these to gauge your own level:

### Beginner Level
- [ ] Can explain JSX syntax?
- [ ] Can create functional components?
- [ ] Can use hooks (useState, useEffect)?
- [ ] Can handle basic events?

### Intermediate Level
- [ ] Can build multi-page apps with routing?
- [ ] Can manage complex state?
- [ ] Can fetch and display data from APIs?
- [ ] Can write tests for components?

### Advanced Level
- [ ] Can optimize performance (lazy loading, memoization)?
- [ ] Can use TypeScript effectively?
- [ ] Can build accessible applications?
- [ ] Can implement advanced patterns (context, portals)?

## How Assessment Works

1. **Skill Inventory**
   - Answer questions about your experience
   - Describe projects you've built
   - Rate confidence in different areas

2. **Gap Analysis**
   - Compare with industry standards
   - Identify weak areas
   - Estimate learning time

3. **Personalized Plan**
   - Recommended resources
   - Project ideas
   - Timeline to proficiency
   - Career next steps

## Industry Benchmarks

For each role, we compare you against:
- Junior developers (0-2 years)
- Mid-level developers (2-5 years)
- Senior developers (5+ years)
- Specialists (10+ years)

## Tips

- Be honest in self-assessment
- Retest every 3-6 months to track progress
- Focus on your biggest gaps first
- Don't try to improve everything at once
- Build projects while learning
- Join communities for accountability
