# Skill Assessment

Evaluate your skills against industry standards. Identify gaps and get targeted improvement suggestions.

## Usage

```
/skill-assessment [role] [--detailed]
```

## Examples

```
/skill-assessment react
/skill-assessment backend --detailed
/skill-assessment ai-engineer
```

## Assessment Includes

- **Proficiency Levels** - Beginner, Intermediate, Advanced, Expert
- **Skill Breakdown** - Score for each component skill
- **Gap Analysis** - What you need to learn
- **Timeline** - How long to close gaps
- **Resources** - Learning materials for weak areas
- **Benchmarks** - Compare with industry standards
- **Recommendations** - Next steps for growth
