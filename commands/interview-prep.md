# Interview Prep

Prepare for technical interviews for your target role. Practice questions, system design, and interview strategies.

## Usage

```
/interview-prep [role] --company [company-name] --type [behavioral|technical|system-design]
```

## Examples

```
/interview-prep frontend-developer
/interview-prep backend-developer --company google
/interview-prep system-designer --type system-design
/interview-prep ai-engineer --company openai
```

## Interview Preparation

- **Role-Specific Questions** - Common interview questions
- **Coding Challenges** - Algorithm problems
- **System Design** - Architecture questions
- **Behavioral Questions** - Soft skills assessment
- **Company-Specific** - Company culture & focus
- **Mock Interview** - Practice with feedback
- **Resources** - Study materials and tips
