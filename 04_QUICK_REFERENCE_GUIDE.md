```

└── {roadmap-id}/

    ├── {roadmap-id}-beginner.json  # Beginner variant (if available)
    ├── {roadmap-id}.md             # Markdown documentation

    ├── migration-mapping.json      # Version mappings
```

## JSON Schema Reference

Every roadmap JSON file has this structure:

```json
{
  "nodes": [
    {
      "id": "unique-id",
      "type": "title|topic|subtopic|paragraph|button|vertical",
      "position": { "x": number, "y": number },
      "width": number,
      "height": number,
      "data": {
        "label": "Display text",
        "description": "Additional info",
        "url": "http://example.com (for buttons)"
      },
      "style": { /* CSS properties */ },
      "selected": boolean,
      "zIndex": number,
      "measured": { "width": number, "height": number }
    }
  ]
}
```

**Node Types**:
- `title`: Section headings
- `topic`: Main categories
- `subtopic`: Detailed concepts
- `paragraph`: Explanatory text
- `button`: Interactive links
- `vertical`: Visual connectors

## Plugin Integration Strategy

### Recommended Data Source
Use GitHub Raw Content URLs for:
- No rate limiting
- Direct source files
- Always current with repository
- Reliable fallback option

### Caching Strategy
Cache roadmap JSON files locally:
- Reduces network requests
- Improves response time
- Store in application cache
- Invalidate on version updates

### Agent Design Pattern
Create specialized agents for:
- Major categories (Frontend, Backend, etc.)
- Individual roadmaps (for detailed queries)
- Cross-roadmap relationships
- Beginner vs. advanced variants

### Metadata Extraction
Parse JSON nodes to:
- Extract skill requirements
- Map learning dependencies
- Categorize topics by difficulty
- Create searchable indices

## Important Notes for Developers

1. **Consistent Naming**: All roadmaps use kebab-case (lowercase, hyphens only)
2. **No Updates Needed**: Adding new roadmaps requires no code changes
3. **Beginner Variants**: Check for `-beginner.json` file for simplified versions
4. **Markdown Available**: Documentation always available alongside JSON
5. **FAQ Content**: Each roadmap includes FAQ component
6. **Community-Driven**: Regular updates from maintainers
7. **MIT Licensed**: Open source and free to use
8. **Large Community**: 224K GitHub stars, 2.1M users
